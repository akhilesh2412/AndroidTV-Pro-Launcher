Siri

Say “Hey Siri, Netflix on TV”. Set it up once per app:

  1. Tap Copy next to an app below.
  2. Open the Shortcuts app → + → Add Action → search Get Contents of URL.
  3. Paste the link into it, then name the shortcut what you'll say, e.g. Netflix on TV.

Play YouTube links on the TV: make a shortcut with Show in Share Sheet on, input URLs, and a Get Contents of URL action with this link plus the Shortcut Input added at the end. Then share any YouTube video to it.
